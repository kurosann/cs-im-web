# CS IM Web V2b 补充说明

日期：2026-10-20
适用仓库：`cs-im-web`

## 1. 本版定位

V2b 不是继续堆配置页，而是把 V1 的统一工作台升级成坐席真正可用的智能工作台。

本版优先覆盖 V2 规划中的 P0 能力：

1. 人工客服 AI 辅助回复填充；
2. 自动翻译与原文保留；
3. 会话摘要、情绪与风险识别；
4. 智能分配；
5. AI 客服员工配置与知识库；
6. 基础提醒与内部协作。

同时保留 V1 的业务渠道、转发渠道、消息日志、Webhook 和设置页面，避免 V2 能力与原有工作台割裂。

## 2. 路由

V2b 提供两套等价入口：

| 页面 | V2b 入口 | 工作台入口 |
| --- | --- | --- |
| 总览 | `/v2` | `/` |
| 聊天室 | `/v2/chat` | `/chat` |
| AI 客服员工 | `/v2/employee` | `/employee` |
| 知识库 | `/v2/knowledge` | `/knowledge` |
| 智能分配 | `/v2/assign` | `/assign` |
| 基础提醒 | `/v2/reminders` | `/reminders` |

`/v2` 入口用于原型验收和 V2 功能演示；日常使用仍从统一工作台导航进入。

## 3. 聊天室

### 3.1 AI 辅助回复填充

- AI 建议只填充到输入框，不自动发送；
- 支持正式、友好、简洁、安抚四种语气；
- 支持重新生成、单条忽略和全部忽略；
- 客服发送前必须人工确认；
- 记录“已填充 / 直接使用 / 修改后使用 / 已忽略”状态；
- 高风险会话显示阻断提示，AI 自动回复暂停；
- 建议卡片展示置信度、知识来源和发送给客户的目标语言文本。

### 3.2 自动翻译

- 客户消息显示原文 + 中文译文；
- 客服消息显示中文原文 + 客户收到的目标语言文本；
- 支持显示/隐藏译文和关闭自动翻译；
- 翻译结果保留原文、目标语言和翻译来源；
- 翻译失败时允许“仅发送原文”，并记录失败状态；
- 订单号、品牌词、链接等专业内容通过术语/原文保留策略处理。

### 3.3 会话摘要

- 右侧 AI Tab 支持查看、编辑和保存摘要；
- 支持 AI 重新生成结构化摘要；
- 摘要包含客户主要问题、已处理事项、待处理事项、涉及订单、客户情绪和后续跟进建议。

### 3.4 情绪与风险

- 会话列表、聊天室顶部和 AI 面板均展示情绪与风险等级；
- 高风险会话显示醒目提示，AI 自动回复暂停；
- 风险信息可随转接一并带出。

### 3.5 客户、订单与历史上下文

右侧面板按 Tab 展示：

- 客户基础信息、会员等级、风险标签；
- 最近订单和业务状态；
- 历史会话与处理结果；
- AI 情绪、风险、摘要和建议记录。

### 3.6 快捷回复与知识库

- 常用语支持搜索、快捷指令、分类、作用域和变量提示；
- 支持个人、团队、租户级常用语；
- 知识库答案可以一键填入输入框，仍需人工确认后发送。

### 3.7 内部备注与转接

- 内部备注有独立样式和“不会发送给客户”标识；
- 转接支持选择团队、人工坐席或 AI 客服员工；
- 转接时要求填写原因，并在消息流中记录系统事件；
- 失败消息支持重试。

## 4. AI 客服员工

AI 客服员工是独立可分配对象，支持基础模式和专业模式：

### 基础模式

- 名称、人设、系统提示词、负责业务；
- 历史消息读取条数；
- 全部账号 / 指定账号绑定；
- 自动回复开关；
- 转人工 / 转中控开关；
- 仅建议 / 半自动 / 全自动三种回复模式；
- 启动、暂停、保存草稿、保存并发布；
- 创建、复制、删除、设为默认；
- 最近执行记录。

### 专业模式

- 知识库分组和文档选择；
- 工具调用权限；
- 知识库置信度阈值；
- 最大自动回复轮数；
- 安全策略与风险提示；
- 配置检查项；
- 账号在线 / 离线与占用状态；
- 测试会话，检查知识命中、风险和回复边界。

## 5. 知识库

- 按产品线分组管理知识库；
- 支持 FAQ、政策、规则和模板；
- 支持中文、English、Español 多语言答案；
- 支持渠道范围、生效时间、发布状态和知识来源；
- 展示命中次数和近 7 天命中率；
- 支持术语保护：订单号、品牌名、链接、金额、日期和型号优先保留原文；
- 支持新增、编辑、发布和下架；
- 知识库与 AI 客服员工配置绑定，不做全局笼统知识池。

## 6. 智能分配

- AI 客服员工、人工坐席和坐席组共用同一套分配规则；
- 规则按优先级从上到下匹配；
- 展示高风险、语言、意图和兜底规则；
- 服务者池展示在线状态、语言、技能和当前负载；
- 支持直接编辑规则名称、匹配条件、分配对象、对象类型和启用状态；
- 超出单坐席上限后进入候补队列；
- 非工作时间优先 AI，高风险转值班；
- 低置信连续失败自动转人工并带上下文。

## 7. 基础提醒

覆盖：

- 会话长时间未响应；
- 高风险客户长时间未认领；
- AI 连续回答失败；
- 消息投递失败；
- 转人工后无人跟进；
- 渠道凭证异常。

提醒列表展示级别、时间、客户/渠道/意图上下文，并支持：

- 按高 / 中 / 低风险筛选；
- 高风险、中风险、低风险待处理数量统计；
- 按提醒类型展示不同图标和颜色；
- 完成、恢复和隐藏已完成；
- 提醒渠道说明：站内、飞书、Telegram，后续扩展企业微信和邮件。

## 9. 当前 Mock 边界

本版仍是前端 Mock-first：

- 不请求真实 AI 模型；
- 不请求真实翻译服务；
- 不连接真实消息网关；
- 不写入真实数据库；
- 管理面登录默认依赖 `/auth/v1/management/login`，纯前端页面验收可注入本地 mock session。

后续接入真实后端时，保持页面和组件不变，将 Mock 数据替换为 Repository / API client 即可。
